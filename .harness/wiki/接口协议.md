# 接口协议

> 所有 API（REST / SSE / WebSocket）必须遵守本协议。
> 服务间通信：REST 主 + Redis Pub/Sub 做事件。

---

## 1. Base URL

```
Development: http://localhost:8000
Test:        http://test.harness.local
Production:  https://api.harness.example.com
```

---

## 2. 请求头

| Header | Required | Description |
| --- | --- | --- |
| `Content-Type` | 是 | `application/json` |
| `Authorization` | 是 | `Bearer {token}` |
| `X-Request-Id` | 否 | 客户端生成的 UUID，全链路追踪 |
| `X-User-Id` | 否 | 部分端点用 |
| `Accept-Language` | 否 | `zh-CN` / `en-US` |

---

## 3. 统一响应格式

### 3.1 成功
```json
{
    "code": 200,
    "message": "success",
    "data": { ... }
}
```

### 3.2 错误
```json
{
    "code": 1001,
    "message": "user not found",
    "data": null,
    "request_id": "5c8b..."
}
```

### 3.3 字段约定
| Field | Type | Description |
| --- | --- | --- |
| `code` | int | 业务状态码；200 = OK，4xx = 客户端错误，5xx = 服务端错误 |
| `message` | string | 人类可读错误信息 |
| `data` | any / null | 业务负载 |
| `request_id` | string | 服务端生成，便于排查 |

---

## 4. 业务状态码

| 范围 | 含义 |
| --- | --- |
| 200 | 成功 |
| 1001-1099 | 参数错误 |
| 1101-1199 | 鉴权 / 权限 |
| 1201-1299 | 资源未找到 |
| 1301-1399 | 冲突 / 状态错误 |
| 1401-1499 | 限流 / 配额 |
| 1501-1599 | 第三方错误（LLM / 向量库等） |
| 1601-1699 | 内容安全（命中拦截） |
| 1701-1799 | Agent 异常 |
| 5000+ | 系统错误 |

## 5. 主要端点

### 5.1 健康
```http
GET /api/health
→ 200 {"code":200,"message":"ok","data":{"db":"up","redis":"up","version":"0.1.0"}}
```

### 5.2 对话（流式）

```http
POST /api/v1/chat
Content-Type: application/json
Authorization: Bearer {token}

{
    "user_id": "alice",
    "kb_ids": ["KB123"],                // 可选
    "question": "如何使用 Python 装饰器？",
    "history": [                        // 可选，短时记忆
      {"role":"user","content":"hi"},
      {"role":"assistant","content":"hello"}
    ],
    "stream": true,                     // 默认 true
    "model": "gpt-4o-mini",
    "temperature": 0.0
}

→ SSE stream
event: message
data: {"code":200,"message":"","data":{"delta":"..."}}

event: message
data: {"code":200,"message":"","data":{"delta":"...", "sources":[{"id":1,"score":0.91,...}]}}

event: done
data: {"code":200,"message":"done","data":{"usage":{"prompt_tokens":120,"completion_tokens":40,"total_tokens":160}}}
```

### 5.3 对话（非流式）
`stream=false` 时返回完整结果 + `usage` + `sources`。

### 5.4 知识库

```
POST   /api/v1/knowledge/kb              # 新建 KB
GET    /api/v1/knowledge/kb             # 列表
DELETE /api/v1/knowledge/kb/{kb_id}     # 删除（HITL 必须）
POST   /api/v1/knowledge/upload         # 上传文件
GET    /api/v1/knowledge/file/{file_id}  # 文件状态
POST   /api/v1/knowledge/search         # 手动检索
DELETE /api/v1/knowledge/file/{file_id} # 删除文件（HITL 必须）
```

### 5.5 HITL

```
POST /api/v1/hitl/{hitl_id}/approve
POST /api/v1/hitl/{hitl_id}/reject
POST /api/v1/hitl/{hitl_id}/edit       # 修改后再执行
GET  /api/v1/hitl/pending              # 待审列表
```

### 5.6 会话历史

```
GET  /api/v1/conversations
GET  /api/v1/conversations/{conv_id}/messages
DELETE /api/v1/conversations/{conv_id}
```

### 5.7 监控 / 管理

```
GET  /api/v1/admin/usage?from=...&to=...     # Token 用量
GET  /api/v1/admin/health
POST /api/v1/admin/cache/clear
```

---

## 6. SSE 规范

- `Content-Type: text/event-stream`
- 每个 `data:` 行是**一行 JSON**（不能换行）
- 客户端可用 `EventSource`（天然支持断线重连）
- 服务端每 15 秒发 `:heartbeat\n\n` 防链路超时

---

## 7. WebSocket 规范（双工）

`ws://host/ws/v1/chat/{conversation_id}`

- 客户端发送 `"text"`（用户输入）
- 服务端返回 `"delta"` / `"tool_call"` / `"sources"` / `"done"` / `"error"`
- 单连接有效时长 30 分钟；过期后客户端需重连

---

## 8. 错误处理约定

| 场景 | HTTP | code | message |
| --- | --- | --- | --- |
| 缺参数 | 422 | 1001 | missing field `xxx` |
| 鉴权失败 | 401 | 1101 | unauthorized |
| 权限不足 | 403 | 1102 | forbidden |
| 资源不存在 | 404 | 1201 | xxx not found |
| Token 超额 | 429 | 1401 | quota exceeded |
| LLM 全档降级失败 | 503 | 1501 | llm service unavailable |
| 内容审核失败 | 403 | 1601 | unsafe content |
| HITL 待审批 | 202 | 1700 | awaiting approval |
