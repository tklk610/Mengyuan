# 工程结构规范

> 适用于 **Python 3.11+ AI Agent 项目**。
> 强制使用 `src/` layout（避免本地包导入陷阱）。
> 业务子目录在初始化时按"Agent 类型"动态选型（参考 `.harness/wiki/agent-templates/`）。

---

## 4. 五层依赖方向（强制）

```
api/  →  agents/  →  tools/  →  repositories/  →  models/
```

| Layer | 职责 | 可以依赖 | **禁止** |
| --- | --- | --- | --- |
| `api/` | HTTP 协议适配 | agents / schemas / 横切 | **不允许**直接调 tools 内部 / repositories / models |
| `agents/` | Agent 定义 + LangGraph 编排 | tools / schemas / 横切 | **不允许**直接调 repositories / models |
| `tools/` | 能力封装 | repositories / schemas / 横切 | **不允许**直接构造 ORM / 写 SQL / 调 agents |
| `repositories/` | 数据 CRUD 抽象 | models | **不允许**调 LLM / Agent / tools |
| `models/` | 数据结构定义 | — | — |

> 📐 graph 节点必须是 thin wrapper：只调 tools/，不做业务计算。
> 违反依赖方向 = 评审直接打回，CI 红线。

---

## 5. 各目录封装边界（不要越界）

| 目录 | 可以 | 不可以 |
| --- | --- | --- |
| `agents/` | 定义 agent + 编排 LangGraph + 调 tool | 不直接写库（持久化走 `tools/`） |
| `llm/` | 包装 OpenAI/Anthropic/国产，支持流式 + 重试 + token 计数 | 不写业务逻辑 |
| `rag/` | 文档加载、切分、向量化、检索、重排 | 不调 LLM 做摘要（应交给 agents/ 编排） |
| `tools/` | 实现能力（搜索 / 计算 / 查库），所有 tool 必须幂等 | 不做业务编排（应交给 agents/） |
| `repositories/` | 数据 CRUD 抽象 | 不调 LLM / Agent / tools |
| `guardrail/` | 文本审核、PII 脱敏、token 计数 | 不调 agents / tools 业务逻辑 |

## 6. 文件放置规则（强制）

| 文件类型 | 必须放置 |
| --- | --- |
| FastAPI 路由 | `src/ai_agent/api/v1/endpoints/` |
| WebSocket | `src/ai_agent/api/v1/websocket/` |
| LangGraph Agent | `src/ai_agent/agents/graph.py`，节点放 `agents/nodes/` |
| Tool 实现 | `src/ai_agent/tools/builtin/{tool_name}.py` |
| LLM 适配器 | `src/ai_agent/llm/{provider}_impl.py` |
| 数据访问 | `src/ai_agent/repositories/{table}_repo.py` |
| ORM 模型 | `src/ai_agent/models/orm/{table}.py` |
| Pydantic Schema | `src/ai_agent/schemas/` |
| Prompt 模板 | `src/ai_agent/prompts/templates/{name}_v{N}.yaml` |
| Alembic 迁移 | `migrations/versions/{rev}_{slug}.py` |
| 单元测试 | `tests/unit/{mirror path}/test_*.py` |

## 7. 模块命名

| 类型 | 规范 | 示例 |
| --- | --- | --- |
| Python 包 | snake_case | `ai_agent` |
| Python 文件 | snake_case | `chat_service.py` |
| 类 | PascalCase | `ChatService` |
| 函数 | snake_case | `stream_chat_response` |
| 变量 | snake_case | `conversation_id` |
| 常量 | UPPER_SNAKE | `LLM_MAX_RETRIES` |
| 数据库表 | snake_case（推荐复数） | `conversations`, `messages`, `knowledge_chunks` |
| ORM 类 | PascalCase（**单数**） | `Conversation`, `Message` |
| Pydantic 模型 | PascalCase（带后缀） | `ChatRequest`, `ChatResponse`, `KnowledgeCreate` |
| REST endpoint | kebab-case | `/api/v1/knowledge-bases` |
| Agent 工具名（Function name） | snake_case | `search_knowledge_base` |

## 8. 红线规则（机械可检）

> **R 编号映射**：本表 1-8 为机械可检技术红线；「Claude.md 红线」列标注实际机制编号（R4 / R6 / R7 / R16）。R9-R16 为 AI 特有红线，详见 `.harness/rules/ai-special-rules.md`。

| 本表 # | Claude.md 红线 | 红线 | 自动化 |
| --- | --- | --- | --- |
| 1 | **R7** | 禁止跨模块导入内部实现（包名必须为 `ai_agent`，禁止随意改名） | CODEOWNERS |
| 2 | **R7** | 5 层依赖方向**不可反转**：`api/` 禁止直接 import `repositories/` 或 `models/`（api → agents → tools → repositories → models） | ruff `TID252` + AST 扫描 |
| 3 | **R7** | 跨工具 / 跨 agent 协调**必须**走 `agents/`，禁止其他层直接调 `tools/` 内部实现 | ruff 自定义规则 |
| 4 | **R6** | 数据库操作**必须**通过 `repositories/`（仅 `tools/` 内部使用），禁止在 `agents/` / `api/` 写 SQL | ruff 自定义规则 |
| 5 | **R4** | Prompt **必须**放 `src/ai_agent/prompts/templates/` YAML 文件，禁止代码中硬编码大段模板 | grep 扫描 |
| 6 | **R7** | 新增文件**必须**按上述目录结构放置 | CODEOWNERS 强制 review |
| 7 | **R6** | 数据库迁移**必须**放 `migrations/versions/`，禁止业务代码内直接 DDL | ruff |
| 8 | **R16** | 单元测试**必须**镜像 `src/` 放置在 `tests/`（含变更留痕检查） | CI 强制 |

> **联动**：本表 R 编号与 `.harness/rules/编码规范.md` §0 映射表是同一体系。任何与 R 编号冲突的解释，**以 `.claude/Claude.md` §4 为准**。
