## 2. 第一项功能落地：以"你好"为例

### 2.1 创建 Pydantic Schema（`schema/chat.py`）

```python
from pydantic import BaseModel, Field

class ChatRequest(BaseModel):
    user_id: str = Field(..., min_length=1)
    question: str = Field(..., min_length=1, max_length=2000)

class ChatChunk(BaseModel):
    delta: str = ""
    sources: list[dict] = Field(default_factory=list)
```

### 2.2 创建 ORM 模型（`model/orm/conversation.py`）

```python
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String, DateTime
from datetime import datetime

class Base(DeclarativeBase):
    pass

class Conversation(Base):
    __tablename__ = "conversations"
    id: Mapped[str] = mapped_column(String, primary_key=True)
    user_id: Mapped[str] = mapped_column(String, index=True)
    created_at: Mapped[datetime] = mapped_column(DateTime, default=datetime.utcnow)
```

### 2.3 创建 Repository（`repository/conversation_repo.py`）

```python
from sqlalchemy.ext.asyncio import AsyncSession
from .model.orm import Conversation

class ConversationRepo:
    def __init__(self, session: AsyncSession):
        self.s = session

    async def create(self, user_id: str) -> Conversation:
        c = Conversation(id=uuid4().hex, user_id=user_id)
        self.s.add(c)
        await self.s.flush()
        return c
```

### 2.4 创建 Service（`service/chat_service.py`）

```python
from langchain_openai import ChatOpenAI
from .llm.factory import get_llm

class ChatService:
    def __init__(self, llm: ChatOpenAI):
        self.llm = llm

    async def chat(self, question: str) -> str:
        resp = await self.llm.ainvoke(question)
        return resp.content
```

### 2.5 创建 API（`api/v1/endpoints/chat.py`）

```python
from fastapi import APIRouter, Depends
from fastapi.responses import StreamingResponse
from .schema.chat import ChatRequest
from .service.chat_service import ChatService

router = APIRouter()

@router.post("/chat")
async def chat(req: ChatRequest):
    """对话（流式 SSE）"""
    service = ChatService()
    async def stream():
        async for delta in service.stream_chat(req.question):
            yield f"data: {delta.model_dump_json()}\n\n"
    return StreamingResponse(stream(), media_type="text/event-stream")
```

### 2.6 跑起来

```bash
uv run uvicorn ai_agent.main:app --reload --port 8000
curl -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"user_id":"alice","question":"你好"}'
```

## 6. 性能 / 可靠性

| 关注点 | 做法 |
| --- | --- |
| LLM 高可用 | 模型降级链 + 熔断 |
| Token 配额 | Redis 配额 + 硬拒绝 |
| 检索延迟 | 向量索引 HNSW + Redis 缓存 |
| SSE 断开 | 心跳 + 客户端重连 |
| 大文件 | 流式切分 |
| 并发 | `asyncio.gather` + `Semaphore` |
| 数据库 | 连接池 + 慢查询日志 |

## 8. 常见陷阱

- ❌ LLM 调用没 timeout / retry
- ❌ Prompt 用 f-string 拼接（注入）
- ❌ 输出不结构化校验
- ❌ 对外副作用工具无 HITL
- ❌ Token 用量没记录 / 没限额
- ❌ PII 没脱敏进日志
- ❌ 测试打真实 LLM
- ❌ 跨层依赖（service 直接 import sqlalchemy）
